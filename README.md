Για να λειτουργήσει αυτή η εργασία, θα πρέπει να έχετε στον υπολογιστή σας το XAMPP, τη MySQL, την PHP, και το LARAVEL.

Αφού εγκαταστήσετε τα παραπάνω, κατεβάζετε τον φάκελο beauty_salon_bookings από το παρακλάδι main και μετά τοποθετήστε τον στην εξής θέση:

Τοπικός δίσκος -> xampp -> htdocs -> dashboard

Οπότε o φάκελος beauty_salon_bookings θα έχει τη διαδρομή C:\xampp\htdocs\dashboard\beauty_salon_bookings

Για την εγκατάσταση της βάσης δεδομένων θα κάνετε τα εξής:

Κατεβάστε το αρχείο beauty_salon_db.sql από το παρακλάδι main.

Ανοίξτε τον πίνακα ελέγχου του XAMPP και ενεργοποιήστε τις επιλογές Apache και MySQL.

Πηγαίνετε στον σύνδεσμο http://localhost/phpmyadmin/ και δημιουργήστε μια νέα βάση δεδομένων με όνομα beauty_salon_db.

Όσο έχετε επιλεγμένη αυτή τη νέα βάση δεδομένων, πατήστε στην καρτέλα Εισαγωγή.

Επιλέξτε το αρχείο beauty_salon_db.sql που κατεβάσατε και πατήστε από κάτω το κουμπί Εισαγωγή.

Στοιχεία για τις κλήσεις του API:

Ο βασικός σύνδεσμος του API είναι: http://localhost/dashboard/beauty_salon_bookings/public/api

και το token επαλήθευσης είναι: secret_token

Οι καταλήξεις είναι οι ακόλουθες:

/appointments

Mέθοδος GET

παράμετροι: 

specialist_id (προαιρετική)

date (εε-μμ-ηη)

Επιστρέφει όλες τις κρατήσεις ενός ειδικού για τη δεδομένη ημέρα.
Αν δεν δοθεί η παράμετρος specialist_id, επιστρέφει τις κρατήσεις όλων των ειδικών για τη δεδομένη ημέρα.

/book

Μέθοδος POST

παράμετροι:

specialist_id

service_id

appointment_date (εε-μμ-ηη)

start_time


Οι ώρες κρατήσεων έχουν οριστεί από τις 9:00 έως τις 18:00 και ανά μισή ώρα.

Η κράτηση αποθηκεύεται στον πίνακα των κρατήσεων.

/cancel

Μέθοδος POST

παράμετροι:

appointment_id


Η κράτηση διαγράφεται από τον πίνακα των κρατήσεων.
